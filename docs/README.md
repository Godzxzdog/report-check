# Робоче місце перевіряючого

Статична версія системи приймання та перевірки звітів підрозділів.
Працює повністю у браузері: файли XLSX читаються локально й нікуди не надсилаються.

- Читання XLSX: власний парсер (ZIP + XML), без сторонніх бібліотек.
- Реєстр подань зберігається в localStorage браузера.
- Резервна копія — файл JSON, відновлення — тим самим файлом.
- Правила перевірки описані в `rules/template.json`.

## Обмеження статичної версії

Оригінали файлів у браузері не зберігаються. Для повторної перевірки
зберігається текстовий зліпок вмісту аркушів.

Локальна версія з повним збереженням оригіналів, SQLite-реєстром і бекапами
на диску — у корені проєкту (`server.py`).
