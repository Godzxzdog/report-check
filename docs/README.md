# Приймання щоденних розрахунків

Статична версія за ТЗ v4.1 і шаблоном v1.3. Працює повністю у браузері.

- Розпізнавання файлу за іменованими клітинками шапки (D3–D9)
- Правила S / H / R / L / N за ТЗ
- Реєстр подань, версії, рішення, реєстр осіб
- Календар подань ПУ × доби
- Місячні довідки про чергування

Дані зберігаються в localStorage браузера. Оригінали XLSX не зберігаються.
